# Water Management in Crops

## OVERVIEW:
This project analyzes 21 farming success stories to understand how water management practices influence agricultural productivity, farm income, and climate resilience. It also explores the applicability of these practices to Chhattisgarh.

## OBJECTIVES:
- Analyze climatic conditions, farm sizes, and crop patterns.
- Explore the relationship between climate and farm income.
- Identify effective water management practices.
- Assess the suitability of these practices for Chhattisgarh.

## FEATURES:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Climate, land size, crop, and income analysis
- Data visualization and insights
- Applicability analysis for Chhattisgarh

## TOOLS:
Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook, Microsoft Excel

## HOW TO RUN:
1. Install the required dependencies:
   `pip install -r requirements.txt`
2. Ensure the input dataset path is correctly configured.
3. Open `data.ipynb` in Jupyter Notebook.
4. Run the notebook cells to perform the analysis and generate visualizations.

## CONCLUSION:
The project highlights how efficient irrigation, rainwater harvesting, farm ponds, and crop diversification can support sustainable agriculture. The findings suggest that suitable water management practices can help farmers manage water scarcity and improve resilience to climate variability.
